# Atlas v0.9.0

Atlas v0.9.0 is the first public portfolio release of the evidence-first gaming-peripheral research product.

## Highlights

- 134 canonical product records:
  - 43 gaming mice
  - 20 mousepads
  - 9 skate families
  - 12 gaming keyboards
  - 50 keyboard switches
- dedicated Mousepads and Switches destinations;
- sourced product comparison with category-specific dimensions;
- shareable Switches filter views;
- 466-entry attributed ThereminGoat switch-review directory kept separate from Atlas canonical specs;
- Product Lab, Sensitivity Lab, Shape/setup tooling, Keyboard Lab and guided physical Validation Lab;
- Cloudflare Worker API and production deployment verification.

## Switches

The Switches catalog now includes manufacturer-backed records from CHERRY, Gateron, Wooting, Akko, Kailh and TTC.

Current switch records require:

- a manufacturer source;
- at least one published force point;
- explicit product media;
- valid travel data;
- an explicit compatibility note for Hall-effect/TMR records.

Switch comparison keeps published force points and travel separate, preserves source units in the UI, and does not create a universal product score.

## Evidence and provenance

Atlas keeps these evidence classes distinct:

- manufacturer claims;
- independent measurements/reviews;
- community observations;
- Atlas-derived/modelled values.

ThereminGoat review metadata remains attributed external evidence. Atlas does not republish ThereminGoat composite scores as Atlas rankings.

Source dates, source references, media paths, switch compatibility caveats and README catalog counts are protected by CI.

## Boundaries

Atlas is a curated research product, not a representative market database.

This release does not claim:

- measured performance where only manufacturer claims exist;
- market share or demand from catalog composition;
- universal magnetic-switch compatibility;
- universal “best” product rankings;
- physical validation results that were never executed.
