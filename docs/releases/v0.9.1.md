# Atlas v0.9.1

Atlas v0.9.1 is a reliability, research-depth and sharing release built on top of the first public v0.9.0 milestone.

## Product and UX

- Browser-local saved gear with shareable shortlist URLs.
- Direct shareable product-detail links with explicit copy-link feedback.
- Cleaner global navigation colors and mobile overflow behavior.
- Product inspectors now show source-check recency so evidence freshness is visible without opening the raw catalog.

## Catalog and research

The canonical catalog now contains **157 products**, including **73 keyboard switches**.

This release expands switch coverage with sourced records from:

- Wuque Studio, including WS Red, Yellow, Brown, Quartz, Silent Linear, Silent Tactile, Morandi and Pearl;
- KTT, including Hyacinth, the full Macaron family, Creamy Ice Cream, Taro Ice Cream and MoonRosa;
- Kailh, including BOX Jade, BOX Silent Pink, Magnetic CPG1515M01D01 and Midnight MX Silent Tactile.

Atlas continues to exclude or defer records when manufacturer pages conflict rather than choosing a convenient value. Examples in this release include KTT Guava and Kailh BOX Navy.

Manufacturer operating force, tactile pressure-point force, actuation/bottom-out fields and magnetic compatibility remain distinct concepts rather than being collapsed into a single score.

## Provenance and media

- Repaired stale catalog source links and restored fit-model provenance/live Finalmouse sourcing.
- Added weekly source-link health auditing.
- Added changed-switch media verification before merge.
- Production media verification now checks binary image signatures instead of treating any successful HTTP response as valid product media.
- Product inspectors expose latest/oldest source-check dates.

## Quality and security

- CI and deploy install strictly from `package-lock.json` with `npm ci`.
- Added one-command `npm run verify`.
- Declared Node 22 as the supported local/CI runtime.
- Added Worker API contract tests.
- Added CodeQL and consolidated public-repository security checks.
- Added CycloneDX SBOM generation.
- Added architecture, reviewer and data-dictionary documentation.
- Added a repeatable release process.
- Automatically prunes merged PR branches.

## Verified release state

The release candidate passed Atlas CI, Security baseline, CodeQL and production deployment verification.

Measured initial payload on the current build:

- JavaScript: **451.04 KiB raw / 113.24 KiB gzip** (budget 460 / 118 KiB);
- CSS: **105.16 KiB raw / 19.58 KiB gzip** (budget 115 / 22 KiB).

The production media smoke test on the pre-release main build returned valid image responses for **128/128 current/announced mice, keyboards and switches**.

## Boundaries

Atlas remains a curated research product rather than a complete market database.

v0.9.1 does not turn manufacturer claims into measured performance, does not infer demand or market share from catalog composition, does not treat magnetic switches as universally compatible, and does not convert external review scores into Atlas rankings.
